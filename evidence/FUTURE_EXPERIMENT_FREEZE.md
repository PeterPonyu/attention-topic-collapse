# Prospective collapse-phase and MLP gate (specified 2026-09-22; NOT RUN)

This document specifies a future study, not a result. The existing twelve-arm study and its three seeds per cell were inspected before writing this protocol; none of its data are independent confirmation of the proposed grid. Do not merge old endpoints into the new seed denominator. This is a computational, fixed-object study; neither seeds nor 450 held-out cells are biological replicates.

## Primary paired MLP gate

Use only the paper-local frozen Setty and Dentate inputs, train/unused-validation/test partition and normalized features, with the same count reconstruction, topic-gene decoder, logistic-normal surrogate KL, free bits, optimizer and 3200-update exposure as the current matched experiment. Replace only the attention encoder with a plain feed-forward MLP on the same 3000-vector (no attention, no batch normalization, no cross-cell operation). Two or more Linear--LayerNorm--GELU blocks and the same ten-dimensional mean/variance output are allowed. Before training, enumerate integer widths and select the width with the closest *trainable whole-autoencoder parameter count* to the attention arm, requiring relative difference at most 1%; freeze the exact topology, counts, implementation hash and initialization rule. If no width meets 1%, add a predeclared narrow bottleneck or adjust one hidden width deterministically, never a dummy unused parameter. The existing stock `encoder_type='mlp'` at width 128 is **not** automatically matched. Decoder and all loss paths must be identical; confirm that changing the encoder only changes encoder parameters. No parameter count or MLP outcome has yet been measured here.

Use new seeds 100--119 for each dataset × architecture × concentration (2 × 2 × 2 × 20 = 160 endpoints). For each dataset/seed, pair concentration arms on the same initial encoder+decoder state within architecture and match the minibatch schedule and per-step randomness; pair the architectures on schedule and random seed, while not claiming identical encoder weights across different shapes. Fix the seed list, code hashes, all inputs and parameter counts *before* first endpoint. No retries selected by performance. Rerun any technical failure from its saved initial state and schedule; log failures and nondeterminism. No tuning on the held-out cells or on collapsed status. If resources preclude the full grid, report complete partial arms only as exploratory, without crossing this gate.

Primary endpoint is strict collapse on all 450 held-out cells, defined already as a single occupied argmax topic *and* maximum coordinate range ≤1e-8 from deterministic softmax(mu). Report x/20 and two-sided exact Clopper--Pearson 95% interval for each dataset × architecture × concentration cell. Primary contrast is the paired Setty α=0.1 difference in collapse indicators (attention minus MLP): retain the 20 discordance pairs and report the difference with paired-seed bootstrap interval (10,000 resamples, fixed resampling seed 20260922), as descriptive computational uncertainty. The gate for attention-specific framing is evidence of a materially larger attention collapse frequency: at least 5/20 more attention-only than MLP-only discordances, with a two-sided exact McNemar/binomial discordance p < 0.05. This deliberately stringent threshold is a decision rule, not a guarantee of power. If MLP collapse is comparable or the gate fails, frame the failure as configuration/prior/optimization specific, not caused by attention. A failure to reject is inconclusive, not proof of equality.

## Phase diagram after the gate

Whether or not the MLP gate succeeds, separately map the within-architecture computational phase diagram on Setty and Dentate with **at least 20 new seeds per full cell**, alpha ∈ {0.1, 0.3, 1}, KL weight ∈ {0, 0.01, 0.1}, per-coordinate free bits ∈ {0, 0.1}, and learning rate ∈ {0.0003, 0.001, 0.003}. Full 3 × 3 × 2 × 3 = 54 cells per dataset/architecture, hence 4320 runs for two datasets and two architectures at 20 seeds. The α axis is formally inert when KL weight is zero; keep those arms as a negative-control identity test, not evidence for an α effect. Use a staged budget only if all predeclared full cells of a slice complete; otherwise label the map incomplete and make no phase-boundary inference. Budget estimate from historical ~20 s/arm GPU timing is ~24 h of pure training for 4320 arms, plus serialization and probes; actual throughput must be calibrated locally and shared GPU scheduled separately. Never label this grid as performed before completion.

Same frozen preprocessing, matched initialization/schedule, 3200 updates, and primary collapse definition apply. Save every seed-level status, exact pair JS, perplexity, range, occupancy, loss and initial/final hashes; include early warning trajectories at epochs {0, 1, 5, 10, 25, 50, 100, 200}: across-cell coordinate range, mean per-coordinate KL *before free-bit clamping*, and attention entropy for the attention arm only. These early signals are exploratory until a separate held-out seed panel establishes out-of-sample predictive calibration. Report rates and exact binomial intervals per cell, no extrapolation across unrun cells. Fix alpha/KL/free-bit/LR values and all thresholds prior to running; do not re-label a post-hoc boundary as prespecified. Computational endpoints do not establish donor or cohort transportability.
